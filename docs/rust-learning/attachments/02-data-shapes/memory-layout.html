    enum：标签加载荷

    一个 enum 的值在任一时刻只是其中一个变体。内存里要记两样：现在是哪个变体，叫标签；这个变体带的数据，叫载荷。所有变体共用同一块空间，所以大小由最大的变体决定。每格一个字节，格里是这个字节的十六进制值。

        节点 6 · 教程 3.2.3 Testcase: linked-list
        
   
        用 Box 串起来的链表
        
   
        enum List { Cons(u32, Box<List>), Nil }。每个节点 16 字节：标签、元素、指向下一个节点的 Box。Box 是一个 8 字节的指针，指向堆上它独占的那个值。
        
  
        
  
        
   
        
    
    
   
        
   
        
   
        
   
        
    
        
     
        不加 Box：大小算不出来
        
     
        enum List { Cons(u32, List), Nil }
        
     
        值就是数据本身。一个 List 里要放下另一个完整的 List，大小 = 4 + 它自己的大小，没有解。编译器报 E0072：recursive type `List` has infinite size。
        
    
        
    
        
     
        加 Box：大小固定
        
     
        enum List { Cons(u32, Box<List>), Nil }
        
     
        里面放的不再是另一个 List，而是指向它的指针。指针的大小和它指向什么无关：标签 4 + 元素 4 + 指针 8 = 16 字节。
        
    
        
   
        
   
        
    
        同一个办法：二叉树
        
    
        enum Tree { Leaf(u32), Node(Box<Tree>, Box<Tree>) }

let t = Tree::Node(
    Box::new(Tree::Leaf(1)),
    Box::new(Tree::Leaf(2)),
);
        
    
        这棵树在内存里是三个 16 字节的值。变量 t 里是两个指针，各指向堆上的一个叶子。格子的宽度按字节数画：指针和标签 8 字节，u32 4 字节。
