# 算法面试文字课程

本目录是从 `daily-work` 中已经完成归纳和质量校准的“算法面试视频课程”成果复制而来的文字版课程，
作为本仓库后续 LeetCode 学习与实践的课程材料之一。它提供知识讲解、题型地图和复习路线，但不自动
创建学习 Program、启动 Lesson、布置练习或判定 mastery。

## 推荐入口

1. 先读[全课程综合](notes/course-synthesis.md)，了解六层能力结构、题型簇、算法模板和复习路线。
2. 通过[课程笔记索引](notes/index.md)选择章节或单课。
3. 需要完整顺序时查看[课程目录](course-outline.md)。
4. 需要跨课先修、对照和迁移关系时查看[知识关系模型](knowledge-model.md)、
   [概念词表](notes/concepts.json)和[关系图](notes/relationships.json)。

## 内容范围

- 11 篇章节综述；
- 70 篇单课笔记；
- 1 篇全课程综合；
- 课程目录及其机器可读版本；
- 150 个概念节点和 97 条课程关系；
- 知识关系模型与来源边界说明。

本目录不包含原始视频、音频、图片、制作 Prompt、模型原始响应、失败重试、计费记录或内部 QA 过程。
这些内容属于课程制作证据，不是后续学习所需的文字课程正文。

## 在 programming-lab 中的使用方式

- 本目录是 `guide-learning` 的只读知识材料，不是学习状态事实源。
- 开始某个 LeetCode 主题前，仍需学习者明确选择目标、范围和 required mastery；课程顺序本身不构成
  启动授权。
- 实践代码继续放在 `leetcode/python/`、`leetcode/cpp/` 或 `leetcode/rust/`，测试放在仓库既有测试
  位置；不要把题解写回本课程快照。
- 学习过程记录、英语反馈和记忆卡片仍分别遵守 `study-log`、`english-coach` 与 `memo-cards` 的独立
  触发和授权边界；本课程不会自动进入制卡输入。
- 课程中的平台、公司题型和外部规则按原材料录制时语境理解；需要当前事实时应另行核验。

## 快照与维护

来源、复制范围和排除项见 [SOURCE.md](SOURCE.md)。本目录按显式迁移任务更新，不与 `daily-work`
自动同步。后续若需要吸收上游修订，应先比较固定来源提交并审阅差异，避免静默覆盖本仓库已经引用的
课程内容。
